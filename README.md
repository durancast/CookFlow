# 🍽️ CookFlow - Sistema de Gestión para Restaurantes

**CookFlow** es una solución SaaS integral diseñada para optimizar la operativa de restaurantes, permitiendo la gestión de pedidos, control de stock y un terminal de punto de venta (TPV) ágil y moderno.

Este proyecto se desarrolla como Trabajo de Fin de Grado (TFG) para el ciclo de **2º de DAW**.

## 📂 Arquitectura del Proyecto

El repositorio está organizado como un **Monorepo**, separando claramente las responsabilidades:

* **`/frontend`**: Aplicación de cliente y TPV construida con **Astro** y **Tailwind 4**.
* **`/backend`**: API REST robusta desarrollada con **Laravel 11**.
* **`/docs`**: Documentación técnica, diagramas de base de datos y guías de configuración.
